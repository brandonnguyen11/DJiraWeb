Frequently asked questions

How do I get my Jira API token?
Log into your Atlassian account at id.atlassian.com, then go to Security → API tokens → Create API token. Give it a name like "DJira", copy the token, and paste it into the /setup command. Never share this token — it gives access to your Jira account.
Where do I find my Jira URL?
Your Jira URL is the base address you use to access Jira — it looks like yourname.atlassian.net. You can find it in your browser's address bar when you're logged into Jira. Use just the base URL, without any trailing paths.
How do I set up DJira in my server?
Invite DJira to your Discord server, then run /setup with your Jira URL, email, and API token. That's it — no dashboards, no OAuth flows. Your credentials are stored securely per user.
How do I create a ticket from a message?
Type /turnintoticket in any channel. DJira will grab the most recent message, use AI to structure it, create the Jira issue, and reply with a link to the new ticket.
Which Jira project do tickets get created in?
Tickets are created in the project you selected during /setup. Each user picks their own project. Run /setup again at any time to switch projects.
Is DJira free to use?
Yes. DJira is free to get started. You can create tickets, connect your Jira workspace, and use all core features at no cost.
Is my Jira API token stored securely?
Yes. Your API token and credentials are stored per user and only used to authenticate requests to Jira on your behalf. You can revoke your token from Atlassian at any time.
Do I need admin permissions to add DJira?
You need Manage Server permission in Discord to invite DJira. Once added, any member can run /setup with their own credentials and use /turnintoticket independently.
